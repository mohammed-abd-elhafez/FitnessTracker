FitnessTracker

Steps, workouts and daily goals in one place. Private by design, English and Arabic (RTL).

Features

  • Daily dashboard with progress rings from Apple Health (steps, distance, active energy)
  • Log workouts, including strength sets, with edit and delete
  • Daily goals, streaks, weekly and monthly charts with VoiceOver support
  • Daily reminder and a home-screen widget

Built with

Swift 6, SwiftUI, SwiftData, HealthKit, Swift Charts, WidgetKit. MVVM with a simplified Clean Architecture and no third-party dependencies.

Project status

The source is published for review and development. The Xcode app, test and widget targets still need to be created in Xcode on macOS before building or running the app.
